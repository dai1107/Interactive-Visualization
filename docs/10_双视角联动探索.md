# 双视角联动探索

本次丰富仍围绕同一份Palmer企鹅数据。主图提供体型和喙部两个探索视角，保留纯气泡与清楚的图例，不叠加回归线。

## 新增功能

| 功能 | 行为 |
| --- | --- |
| 体型视角 | 横轴鳍长、纵轴体重；默认面积喙长、深浅喙深 |
| 喙部视角 | 横轴喙长、纵轴喙深；默认面积体重、深浅鳍长 |
| 四指标编码 | 面积与深浅均可从四个原始测量字段选择，附相应单位和固定尺度 |
| 同类聚焦 | 悬停或键盘聚焦时临时淡化其他物种；不改变数据、统计或选择范围，可关闭 |
| 物种卡片 | 显示当前个体范围内各物种的n、r和纵轴均值；点击仅看该物种，清除旧框选 |
| 观察提示 | 根据当前坐标和样本重新计算，区分总体相关与物种内相关；处理空集、少量样本和无变化坐标 |
| 播放控制 | 慢速2200ms、标准1400ms、快速800ms；可选择循环播放真实2007—2009年 |
| 联动 | 坐标、相关系数、数值框选、年度指标和说明随视角更新；A/B保存和恢复包含视角及视觉编码 |

面积按原始值比例编码。深浅固定域为喙长30—60mm、喙深13—22mm、鳍长170—235mm、体重2500—6500g。两种视角使用固定坐标范围，跨年份不自动变动。

年度图可选择四项测量的物种均值，沿用物种、性别和岛屿条件，分别汇总三个年份，不应用当前年份限制或主图矩形框选。比较小图始终使用相同的当前视角坐标及默认编码；各组保存时的视角写在条件说明中，恢复时完整还原。明细表和CSV保留四项测量值。

## 验证结果

25项Node测试通过。新增检查包含解析数据上的双视角统计、解析已知直线的正负相关与常量情形、按喙字段框选、体重面积比例、以及随坐标和分组更新的观察提示。原始CSV哈希与342条有效记录核验继续通过。

真实浏览器检查：

- 默认体型视角：2007年109条，r=0.849。
- 全年份喙部视角：342条，r=-0.235；物种内r约为阿德利0.391、帽带0.654、巴布亚0.643。观察提示说明总体与组内方向不同，不将其解释为因果或显著性。
- 点击帽带卡片：保留全部年份，变为68条，r=0.654；显示全部物种后回到342条。
- 聚焦P001：其他两个物种共191条临时变淡，统计仍为342条；关闭聚焦后没有自动淡化。
- 喙部范围38—48mm、16—20mm：107条，r=-0.198。切回体型视角清除旧范围；恢复A后还原喙部视角、107条及38/16的输入下限。
- 快速循环：2007→2008→2009→2007，回到2007年时仍在播放，物种概览为3个气泡；暂停正常。
- 850px及390px视口无水平溢出，物种卡片、图例与五列明细可读。
- 最终浏览器错误日志为空，刷新后恢复默认体型视角和3张物种卡片。

没有新增数据源、生成观测或插补缺失值；年份之间仍是不同观测样本，不能解释为同一个体成长。
