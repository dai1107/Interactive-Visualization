# 设计与统计口径

研究问题是：2007—2009 年 Palmer 群岛样本中，鳍长与体重的关系在不同物种和性别中是否一致？用户可比较总体与分组关系、限定局部范围，再保留两组样本复核差异。

## 数据与编码

原始 [CSV](../EDA_企鹅数据探索/penguins.csv) 共344条，主图使用342条鳍长和体重有效的记录；9条性别未记录的有效观测保留在“全部性别”中。年份分区为2007年109条、2008年114条、2009年119条，默认显示2007年。三个年份不是同一个体的连续追踪。

| 编码 | 体型视角 | 喙部视角 |
| --- | --- | --- |
| 横轴 | 鳍长，170—235 mm | 喙长，30—60 mm |
| 纵轴 | 体重，2500—6500 g | 喙深，13—22 mm |
| 色系 | 物种：阿德利石板蓝、帽带铜橙、巴布亚松绿 | 同左 |
| 默认面积 | 喙长 | 体重 |
| 默认深浅 | 喙深 | 鳍长 |

位置承担主要比较任务。面积从零起算，半径按平方根缩放；深浅使用固定字段范围。编码可切换四项测量，或使用等大点、关闭深浅。物种均值模式用均值位置和样本量面积，不把三个均值当作三个个体计算相关。

筛选后坐标范围保持固定，A/B共享坐标。散点位置保留个体和点群；箱线图不足以作为关系主图，散点矩阵会分散当前问题，岛屿则作为筛选背景。辅助信息通过标签和菜单展开。

## 选择与多视图联动

年份和分类先定义可选范围，局部规则再从中选取记录。主图、n、均值、Pearson r、明细和相关性透镜共用选择状态。

- 选择支持替换、加选、交集和减选，按顺序保存，并可撤销、重做。
- 切换体型与喙部视角保留选中记录，以表达跨指标条件；改变年份、分类或个体/均值模式时清除局部选择。
- 主图框选与分布反向选择互相联动。分箱通常左闭右开，最后一个分箱包含最大边界。
- 分布对照将当前选中与同年其余有效样本并列，各组按自身样本数归一化；参照范围不受当前分类筛选限制。
- 相关性透镜在同一刻度上比较总体、分组与组内合并相关；组内合并先减去各组均值，再计算残差相关，不平均各组的r。

## 比较与记录

A/B快照保存当时的记录、完整条件和编码，后续操作不改写快照。四指标差异图按原单位显示B−A均值差，各指标使用独立固定刻度；不同指标间不按线段长度排名。交集、并集及两侧差集可送回主图。

探索记录本在本浏览器保存完整条件与观察，恢复和导入时用原始CSV重算统计，最多20条。支持JSON备份和Markdown素材导出；A/B仅保存在当前页面会话。

## 可复核的探索案例

| 条件或操作 | 结果 |
| --- | --- |
| 合并全部年份 | n=342，体型r≈0.871 |
| 全部年份切到喙部 | 总体r≈−0.235，各物种内部均为正；组内合并r≈0.528 |
| 鳍长180—200 mm、体重3000—4000 g | n=144，体型r≈0.218 |
| 与喙长38—48 mm、喙深16—20 mm取交 | n=69 |
| 再减去体重3500—4000 g分箱 | n=23；前后两组选集差46条、交集23条、并集69条 |
| 全部年份的帽带雌雄对照 | 各34条，平均体重差约411.8 g；体型r约0.242与0.665 |

这些是当前样本的描述性结果。范围限制本身会改变相关，不能据此推断因果或显著性；岛屿与物种构成也有关。完整审计值见 [data-audit.json](data-audit.json)。

## 布局与反馈

探索、发现、比较、记录和助手分为五个工作区。桌面端左侧筛选、右侧主图；相关性、分布、年度和明细通过标签切换。手机端折叠筛选，并顺序排列比较与记录。

深墨绿页眉、暖灰页面、暖白图表画布建立层次。物种色系贯穿图例与图形，选择同时使用轮廓和文字。短动画用于导航与气泡变化；统计立即显示真实值，快速操作中断旧过渡。可关闭动效，并遵循系统减少动态设置。

当前测试覆盖数据审计、年份与分类、面积及深浅、选择代数、分箱边界、快照与记录、相关性及助手协议。既有浏览器验收核对过上述探索案例、键盘路径及窄屏布局；未进行定量可用性试验。

## 大模型辅助探索

问题与当前视图发送到助手后端，后端由同一CSV重算证据后调用DeepSeek。回答包含解释、后续问题和可选候选视图；字段受校验，候选n和r由前端重算。用户确认后才应用，支持撤销与写入观察草稿；图表条件变化会禁用旧建议。

线上真实回答已由拥有者确认；云端候选应用与撤销尚未单独验收。结构合法不代表解释正确，模型结果需核对。部署、访问口令及错误处理见 [部署说明](deployment.md)。
