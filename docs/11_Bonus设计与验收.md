# Bonus：从交互到可复核的发现

本次沿用原来的 Palmer 企鹅数据与研究问题，增加五步发现之旅、联动分布与物种构成、可恢复的探索记录本。访问 [线上作品](https://dai1107.github.io/Interactive-Visualization/?v=bonus-20261112d#discovery)，点击“开始发现之旅”即可演示。

## 与作业加分方向的对应

作业原文将高级交互、新颖可视化元件、有效多视图协同、优雅设计和有洞察力的探索列为加分方向，并未规定逐项分值。下表说明作品中可展示的设计，不把实现某个功能等同于确定获得某个分数。

| 加分方向 | 可演示的实现 | 对探索的作用 |
| --- | --- | --- |
| 高级交互 | 五步预设可前后导航；任意调整进入自由探索；恢复开始前条件与 A/B；记录本导出、导入与恢复 | 把发现过程变成可以继续、比较和复核的操作路径 |
| 可视化元件 | 气泡位置、面积、色系、深浅表达原始测量与分组；选中/其余的并列比例直方图、物种构成条 | 同时观察关系、分布形状与样本构成；不以装饰代替数据编码 |
| 多视图协同 | 原生拖动框选同时更新强调、统计、物种卡片、分布、构成与明细 | 从散点中的局部位置追查“选中了什么”和“其余样本是什么” |
| 视觉设计 | 保持纯气泡主图与固定跨年坐标；引导、主分析、对照、记录依次展开；复杂功能默认收起 | 保持主问题突出，降低线条和控件叠加造成的干扰 |
| 洞察与故事 | 从体型总体关系切换到喙部，再拆分物种、限制范围、比较雌雄 | 让用户观察总体关系与组内关系的差异，而非仅观看动画 |

Bonus第一版未接入LLM，原有动态观察文字仍根据数据规则计算。后续已加入DeepSeek兼容助手并完成本机真实调用和图表联动验收，详见[LLM真实交互与部署](12_LLM真实交互与部署.md)；线上调用仍需另部署后端，不能把已有规则提示当作模型回答。

## 建议演示顺序（约三分钟）

1. 点击“1 看总体”：合并三个年份，342 条有效记录，鳍长与体重的总体 r=0.871。比较物种卡片，指出不同物种的分布位置不同。
2. 点击“2 换个视角”：喙长与喙深的总体 r=-0.235，而三个物种内部的 r 均为正（约0.391、0.654、0.643）。这说明混合分组后的总体趋势不能替代组内趋势，不能据此认定因果。
3. 点击“3 拆开物种”：只看帽带企鹅，68 条，喙部相关 r=0.654。对比上一场景，理解分析粒度为什么重要。
4. 点击“4 框选局部”：体型范围为鳍长180—200mm、体重3000—4000g，选中144条，r=0.218；其余198条，r=0.821。查看两组分布与物种构成：选中组为阿德利100条、帽带44条，没有巴布亚。限制范围本身会改变相关系数，不能把差异直接解释为生物机制或显著性。
5. 点击“5 雌雄对照”：主图显示帽带雌性34条；A/B分别保存雌性与雄性，各34条。比较时使用当前视角的相同坐标和默认编码。写下观察，点“记下此刻”；展开记录本，可以下载报告素材或JSON备份。

各步骤使用预设的完整条件，而不是在上一组任意筛选上叠加。手动改年份、物种、性别、岛屿、坐标或框选会转入自由探索；“恢复开始前”恢复启动引导前的视图条件及 A/B 组。普通 A/B 快照刷新后清空，探索记录本则保存在当前浏览器。

## 联动与统计口径

- 有效样本：原始344条中，342条鳍长与体重有效。这342条也具有四项测量。没有插补、生成或新增数据源。
- 参照范围：按当前单年或合并年份，取全部有效观测，不受物种、性别和岛屿筛选限制。选中组应用当前分类筛选与矩形范围；其余组为同年参照减去选中编号。两组没有重合，数量之和等于参照数量。
- 分布：可选择体重、鳍长、喙长、喙深。固定分箱，纵轴是各组自己的比例，查看柱形可读实际条数。零样本组不制造比例；选择全部参照样本时明确说明没有其余组。
- 构成：两组各自归一化为100%，颜色沿用物种。标题始终给出n，避免将占比误解为总量。
- Pearson r：按当前坐标的个体测量计算，样本少于3或坐标无变化时显示不可计算。物种均值气泡没有当作独立个体参与r计算。
- 年度图继续沿用分类条件，忽略主图年份限制与框选，明确显示自己的口径。三个年份是不同观测样本，不能视为同一个体成长轨迹。

## 探索记录与可复核性

每条记录保存时间、标题、用户观察、分类与年份条件、坐标视角、面积/深浅编码、年度/分布指标、矩形范围及原始样本编号。恢复时从原始数据重新筛选；导出的Markdown重新计算n、总体和物种内r，附筛选条件、范围、来源与描述性统计限制，可作为报告素材继续编辑。

JSON备份包含格式版本与CSV内容的FNV-1a64数据版本标识。它用于识别数据版本，不是防伪签名。导入最多256KB、20条记录，验证视角、字段、分类、年份、范围和编号与实际筛选结果是否一致；文件自带的统计字段不被信任。用户文字使用文本节点展示，导出Markdown时转义。已有编号的记录保留本地版本，避免覆盖；删除可撤销上一次操作。

记录保存在浏览器localStorage，不上传服务器。浏览器清理存储、更换设备或不同站点来源不会自动保留，建议导出JSON备份。存储不可用时仍可在本次会话导出。

2026-11-12验证：31项Node测试全部通过，包括6项新增的引导统计、同年参照分区、固定分箱边界、数据版本、记录导入复核与报告转义测试；原始CSV哈希仍与独立审计一致。

真实浏览器检查已完成：

- 五步的有效样本数依次为342、342、68、144、34；关键r与上文一致。
- 第五步A/B各34条；切换喙部视角后，两幅小图实际显示喙长/喙深坐标；恢复B还原保存时的体型视角及雄性条件。
- 恢复开始前条件回到2007年109条，同时恢复原来的A/B状态。
- 原生鼠标拖动框选一次得到135条，统计、明细135行及对照135+207=342同步更新，并转入自由探索。
- 导出的JSON含144个真实编号，Markdown含n=144、r=0.218与范围；导入复核成功，恢复后还原144条/198条对照；刷新后仍有保存记录。
- 零样本时显示r不可计算，禁止保存空记录；分布与构成保持空状态。
- 390、850及默认1280px视口无水平溢出；临时视口已重置。最后一次刷新后的浏览器错误和警告日志为空。
- 单文件离线HTML已重新生成，脚本语法通过检查，无外部脚本、样式或数据请求；嵌入的可下载CSV与原始文件字节一致。

## 可用于报告的设计说明

> 为避免交互停留在单个散点图的筛选，我将作品组织为从总体到局部的发现路径。用户先观察体型总体相关，再通过喙部视角和物种拆分比较不同分析粒度；随后使用框选，将位置中的局部样本与同年其余样本的测量分布和物种构成联系起来。联动图采用共享分箱与组内比例，并持续显示样本数，使样本量、分组混合和范围限制对相关性的影响更容易被识别。最后，探索记录本保存完整条件和原始样本编号，支持恢复、数据复核及报告素材导出，让发现过程可重复。所有结论都来自原有观测，界面明确区分描述性相关、分组差异与因果解释。
