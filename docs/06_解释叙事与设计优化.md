# 第五阶段解释叙事与设计优化

2026 年 11 月 11 日完成实施清单中“解释与叙事”和“设计优化”的实现。此次继续使用静态 CSV、Vega-Lite 与原生 JavaScript，沿用原网址和视觉风格，没有增加 LLM、外部 API、字体或图片依赖。

## 一 有依据的探索叙事

新增五步引导，用户可以任选一步，也可以用上一步、下一步顺序操作：

| 步骤 | 实际应用的条件 | 验收参考 |
| --- | --- | --- |
| 看全体 | 全部物种、全部性别，无框选 | n=342，r≈0.871 |
| 只看帽带 | Chinstrap、全部性别，无框选 | n=68，r≈0.642 |
| 看雌性 | Chinstrap、female，无框选 | n=34，r≈0.242 |
| 看雄性 | Chinstrap、male，无框选 | n=34，r≈0.665 |
| 选一片局部 | 全部物种与性别，鳍长 180—200 mm，体重 3000—4000 g | 子集 n=144，r≈0.218；基准仍 n=342 |

引导按钮直接应用相应的筛选和原生框选状态，不只是切换一段介绍文字。选择状态使用可读名称、序号、深色背景及 `aria-pressed` 表示；加载期间禁用，首尾步骤有明确的前后导航状态。

点击“自由探索”保留当前筛选和框选，只退出引导。手动改变筛选或框选时退出当前引导状态，避免仍将不匹配的数据标为某个故事步骤。切换步骤清除固定个体详情；缩放窗口保留当前引导与数据范围。

## 二 当前观察与图中注释

“当前观察”从实际基准与框选子集计算说明，覆盖混合物种、单一物种、性别分组、局部范围、空结果、小样本和不可计算等状态。

例如，全体视图同时给出总体 r 和各物种内 r，引导用户思考混合样本与组内关系；单一物种视图可列出其雌雄样本数及 r；框选时说明子集样本数、平均体重和相对基准的均重差。筛选清空后说明也随之清空，不保留旧结论。所有数值根据当前数据计算，不是硬编码的叙事结论。

散点图新增菱形物种均值标记与中文标签：

- 横坐标为当前探索范围内该物种的平均鳍长，纵坐标为平均体重。
- 未框选时使用筛选基准；有框选时使用子集，只有组内 n≥3 时显示。
- 菱形是汇总，不代表一条个体记录，不参与样本数或相关系数计算，也不能当作个体固定详情。
- 标签根据位置向内排列，使用不同的上下偏移减少遮挡；“标注物种均值”可随时关闭。
- 关闭或样本不足时，图例说明同步提示原因，原始散点和统计不变。

本次选择说明组间差异和有明确边界的局部范围，不把极端点直接标为错误，也不将组均值当成物种识别规则。页面继续注明相关不代表因果、框选限制变量范围、分组差异未经显著性检验。

## 三 设计优化

| 方面 | 改动及目的 |
| --- | --- |
| 信息层次 | 引导放在筛选前；当前观察放在主图后；使用“筛选基准”和“框选子集”文字及范围标记区分口径 |
| 字体与对比度 | 增大坐标轴、表格、操作提示、详情与辅助文字；辅助色 #586961 在底色 #f5f4ef 上的对比度约 5.28:1 |
| 操作目标 | 主要按钮、下拉框、数值输入及引导导航至少 44 px 高；已选物种有边框与底色，状态不只依赖色点 |
| 移动布局 | 引导步骤改为两列，末步独占一行；物种控件保持紧凑三列；侧栏统计和详情改为纵向，避免数字挤入详情 |
| 反馈与可访问性 | 当前步骤、自由探索、标注开关、框选范围均有文字反馈；保留可见键盘焦点、语义化表格和减少动态效果设置 |
| 图表清晰度 | 组均值使用与圆点不同的菱形；标注层不截获指针；保持坐标范围、物种颜色和计数口径 |

以上为已实现的样式与状态规则。浏览器连接主机不可用，本次未完成真实浏览器截图、键盘焦点、鼠标点击和手机布局实测，不能将程序检查称为视觉验收通过。

## 四 检查结果与手工验收

`node --test tests/data.test.mjs` 共 12 项通过。其中 9 项覆盖原功能，新增 3 项检查：

1. 五个引导预设与独立数据核查及既有框选示例一致。
2. 动态观察跟随实际范围变化，空结果、小样本和不可计算不输出旧数值或 NaN。
3. 物种均值为实际分组测量值；Vega 能导出含中文标注的 SVG，清除标注后仍有 342 条个体记录且坐标域不变。

另外检查 JavaScript 语法、HTML 元素引用和重复编号，以及静态资源与数据文件一致性。发布后的核验使用既有 `scripts/github_pages.py inspect` 和 `scripts/check_site.py`。

打开 https://dai1107.github.io/Interactive-Visualization/ 后，建议检查：

- [ ] 点击五个引导步骤，对照上表核对 n/r；第五步同时出现矩形和联动结果。
- [ ] 点击“自由探索”，当前数据不变化；再手动筛选，当前步骤不再保持选中。
- [ ] 点击上一步、下一步，首尾按钮状态正确，加载时不能误操作。
- [ ] 关闭均值标注，菱形和标签消失，但散点、统计和框选不变化；打开后恢复。
- [ ] 手动清空筛选或框选空区域，观察文字不再解释此前的数据。
- [ ] 手机或窄窗口下检查引导、控件、统计和详情；用 Tab、空格、回车操作引导、筛选及标注开关。

报告中可将五步引导解释为“为探索提供入口”，将动态说明解释为“基于当前数据的描述性反馈”。它们不替代用户操作，也不由语言模型推断数据中没有的原因。
