# 气泡面积与深浅编码

根据用户对气泡大小、颜色深浅的反馈，增加可以直接读出数据含义的视觉编码。沿用原始344条观测，其中342条鳍长和体重有效；不增加、插补或改写数据。

## 视觉含义

| 图形通道 | 个体样本 | 物种概览 |
| --- | --- | --- |
| 横轴 / 纵轴 | 鳍长 / 体重 | 平均鳍长 / 平均体重 |
| 色系 | 蓝色阿德利、橙色帽带、绿色巴布亚 | 同左 |
| 气泡面积 | 默认喙长，可切换喙深或等大点 | 当前条件下的样本数 |
| 颜色深浅 | 默认喙深，可切换喙长或关闭 | 对应喙指标的物种内均值 |

个体气泡整体增大，主图最大半径由8改为14像素，面积仍与原始值成正比。例如，喙长55mm与35mm的面积比为55/35，不截断面积尺度或人为放大数据比例。喙长面积最大参考60mm，喙深22mm；物种样本数仍以151为最大参考。

深浅采用固定数值域：喙深13—22mm、喙长30—60mm。同一色系中，数值越大，颜色越深；保持物种色相并调整HCL亮度。圆点使用实色，避免重叠后自动加深被误读为更大的喙指标。框选外的淡化表示未选中，与数据深浅分别控制。

## 交互与说明

- 主图上方同时显示面积图例和三种色系的深浅数值图例，从`#explorer`进入即可看到。
- 两个编码选择器分别控制大小和深浅；切换时平滑过渡。关闭深浅后只保留三个物种颜色。
- 悬停或键盘聚焦显示原始喙长、喙深及当前编码；物种概览显示均值和样本数。
- 年份播放沿用固定尺度。A/B条件恢复包含深浅选项；比较小图统一使用喙长面积和喙深深浅。
- 框选只改变选择状态与统计，不改写数据编码；变换深浅指标后仍保留框选。

## 验证

22项Node测试全部通过，包括原始CSV哈希、有效记录数、面积比例、固定深浅尺度，以及三个色系实际渲染颜色的感知亮度单调性。

真实浏览器检查：默认2007年109个体有72种不同填色，半径约10.55—13.95px，实际填充不透明度为1。等大点且关闭深浅时只有一种半径、三种物种颜色。物种概览播放到2009年正常停止，三物种人数52/24/43，深浅来自各物种实际平均喙深。

合并年份后框选180—200mm、3000—4000g仍为144条；切换深浅后仍保留144条，198条框选外记录仅作选择淡化。保存A并改变深浅选项后，恢复A可恢复原深浅设置及框选。P001详情与原始数据一致：喙长39.1mm、喙深18.7mm。

850px及390px视口无水平溢出；图例按窄屏改为纵向。最终浏览器错误日志为空。单文件HTML与仓库运行模块使用同一份数据与编码逻辑。
