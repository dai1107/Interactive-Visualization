# 第五阶段刷选联动与基准比较

本阶段完成实施清单中“多视图协同”和“更有价值的比较”两项。原有物种与性别筛选、个体详情、重置及数据来源继续保留，新增散点矩形框选、体重分布联动和子集与基准的比较。实现不引入额外依赖、公共 API 或自定义后端。

## 一 两项功能如何落实

| 清单项目 | 新增功能 | 用户能回答的问题 |
| --- | --- | --- |
| 多视图协同 | 从散点图空白处拖动框选，直方图同步高亮子集；分物种统计和明细表也跟随框选 | 这片点群的体重分布如何，包含哪些物种与记录 |
| 更有价值的比较 | 同时选择多条记录，并列比较基准与框选子集的 n、平均体重和 r，显示选中占比与均重差 | 当前局部样本与当前筛选范围整体有何不同 |

鼠标矩形框选使用 Vega-Lite 原生 interval selection。数值范围输入写入同一原生选区，确保矩形、选区数据和散点透明度使用同一套范围。点击单个点保留用于个体详情；框选从图中空白处开始，避免点击个体时误清除选区。

## 二 数据范围与比较口径

**筛选基准**是当前物种与性别筛选后的全部有效记录；**框选子集**是在该基准内，同时满足鳍长和体重范围的记录。框选范围的上下边界均包含，原始 CSV 不修改。

- 右侧“筛选基准 n”和“基准相关 r”始终说明基准，框选时不改成子集数值。
- 新增对比表并列显示基准与子集的样本数、平均体重 g 和 Pearson r。
- 子集占比 = 子集 n / 基准 n；均重差 = 子集平均体重 − 基准平均体重。
- 未框选时，子集行显示“未框选”，直方图只显示基准，分物种统计和明细表使用基准。
- 已框选但未选中记录时，子集 n=0，均重和 r 为“不可计算”；明细表为空，基准仍保留。
- n<3 或变量零方差时 r 不可计算；小样本提示继续保留。

直方图以 250 g 等宽分箱覆盖 2500—6500 g。普通分箱左闭右开，最后一箱包含 6500 g。灰柱显示基准计数、绿柱显示子集计数，两者使用相同分箱及计数轴；分箱计数表提供可访问的文字等价内容。图形使用数量而非归一化比例，避免把不同样本量的柱高误读为相同人数。

矩形范围直接由鳍长和体重定义，会限制变量的分布，因此子集 r 可能随选区变化。页面明确提示：这只是描述所选样本，不能据此认定相关强度存在统计显著差异，也不能作因果解释。

## 三 状态与恢复规则

| 操作 | 状态变化 |
| --- | --- |
| 从散点图空白处拖动 | 更新选区，高亮选中点，弱化区外点，联动分布与统计 |
| 输入四个数值后应用 | 更新同一个原生选区；下限须小于上限，输入须在图形坐标范围内 |
| 单击选中点 | 固定个体详情；拖动结束产生的点击不用于意外固定个体 |
| 清除框选或双击图形 | 清空选区，保留物种与性别筛选，分组统计和明细表恢复基准 |
| 切换物种、性别或全选物种 | 清除旧选区并提示，重新计算基准，防止沿用旧范围造成误解 |
| 重置全部 | 恢复三种物种、全部性别、无框选、无固定详情 |
| 固定个体不再属于子集 | 清除固定详情并提示 |
| 改变窗口宽度 | 按数据单位保留选区，再映射到新的像素坐标 |

数值范围输入、清除按钮、明细表及分箱计数表提供键盘和触屏的替代操作路径。分物种统计和明细表在有框选时只描述子集，页面会注明当前范围。

## 四 程序检查

`node --test tests/data.test.mjs` 共 9 项测试通过，在第四阶段的 6 项回归检查上新增：

1. 矩形上下边界、空子集、在现有筛选范围内选择及未选择状态。
2. 分箱边界与数量守恒：基准分箱总数等于基准 n，子集分箱总数等于子集 n，每箱子集不超过基准。
